# Система верификации дикторов

Курсовая работа: верификация дикторов с помощью модели **ECAPA-TDNN** (SpeechBrain).  
Приложение сравнивает два голосовых образца и определяет, принадлежат ли они одному человеку.

---

## Быстрый запуск (Windows)

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git
   cd ВАШ_РЕПОЗИТОРИЙ
   ```

2. Дважды кликните **`run_app.bat`** — он сам установит зависимости и запустит приложение.

3. Браузер откроется автоматически по адресу `http://localhost:8501`

> При первом запуске модель (~80 МБ) скачается автоматически — займёт ~1 минуту.

---

## Ручная установка (если run_app.bat не подходит)

```bash
pip install -r requirements.txt
```

> Для Windows обязательно установить именно `torch==2.1.2` — новые версии конфликтуют с torchaudio.

```bash
set HF_HUB_DISABLE_SYMLINKS_WARNING=1
set HUGGINGFACE_HUB_DISABLE_SYMLINKS=1
streamlit run app.py
```

---

## Требования

- Python 3.9 – 3.11
- Windows 10/11
- Интернет при первом запуске (для загрузки модели)
